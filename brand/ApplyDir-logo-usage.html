ApplyDir — logo usage

One page. Everything else is in the identity document.

Primary

Horizontal lockup on white or stone. Default for headers, sidebars, documents, decks.

Reversed

On ink or on darkened photography. Contrast must clear 4.5:1.

Stacked

Square formats, merchandise, covers, auth screens. Never mix with the horizontal on one surface.

Clear space

x = the width of the crossbar, on all four sides. Nothing enters that field — no type, rules, photographs, or other logos.

Two cuts of the symbol

The standard cut at 32 px and above. Below that, the small cut thickens the arms and widens the counter so the letter survives the pixel grid. It is the only permitted redraw.

Colour

Signal Orange#FF5B2E
Ember#B82E07
Ink#101010
Stone#F4F2F0

Roughly 70% white or stone, 25% ink, 5% orange. If a screen looks orange, it is wrong. Orange never sets body copy and never fills a large background.

Misuse

  • Never stretch or condense. One aspect ratio; scale proportionally.
  • Never rotate. It points right. Rotated, it is just a letter and the idea is gone.
  • Never recolour. Orange, ink, or white. No gradients across the mark, no borrowed category colours.
  • Never outline, emboss, or add shadow. It is a flat mark.
  • Never place on a mid tone. On photography, reverse it on a darkened field.
  • Never fill the counter. The one piece of negative space carries the letter.
  • Never re-typeset the wordmark. Use the supplied outlined files or the Logo component.
  • Never repeat it. One mark per surface.

In code

Import the component; do not inline raw SVG or re-export from a design tool.

import Logo from "@/components/brand/Logo";

<Logo height={26} />                    // sidebar on white
<Logo tone="reversed" height={28} />     // auth screens on #0B0C10
<Logo variant="mark" small height={16} />// tab, avatar, inline
<Logo variant="stacked" height={120} />  // covers, square formats
<Logo tone="mono" />                     // inherits currentColor
